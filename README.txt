SEVERO — файлы последней опубликованной версии сайта.

Распакуйте архив, затем откройте SEVERO/index.html в браузере. Для публикации загрузите содержимое папки SEVERO на статический хостинг.

В комплекте: HTML, CSS, JavaScript и все 10 изображений одежды. Шрифты загружаются из Google Fonts при наличии интернета; предусмотрены запасные системные шрифты.

Модели, материалы и цены — демонстрационные. Изображения созданы с помощью ImageGen. Заказ можно собрать, скопировать и сохранить в TXT; отправка продавцу, оплата и доставка не подключены.
