SEVERO — концепт бренда мужской одежды для портфолио

Опубликованный адрес: https://danilvoitov.github.io/SEVWRO11/

Статический сайт без сборки и сторонних JavaScript-зависимостей.
Для локальной работы: python3 -m http.server 4173 --bind 127.0.0.1
Затем откройте http://127.0.0.1:4173/.

Возможности:
- три готовых образа с подборками вещей;
- статический HTML-каталог, фильтры и избранное;
- карточки с увеличением фото, выбором размера и условными рекомендациями по уходу;
- локальный гардероб, изменение количества, копирование и сохранение TXT;
- мобильное меню и управление с клавиатуры;
- арт-дирекшн «Тактильное ателье»: тёмная палитра, фактуры и асимметричные образы;
- плавные появления, деликатное движение фото и анимированные фильтры;
- системное уменьшение движения и ручное отключение анимации;
- адаптивные WebP, Open Graph, canonical, sitemap и CreativeWork JSON-LD.

Файлы:
index.html — структура и статический каталог.
style.css — адаптивный дизайн.
app.js — данные товаров и взаимодействия.
motion.js — анимация, управление движением и фактуры.
assets/README-assets.txt — происхождение изображений и промпты ImageGen.
scripts/generate-catalog.mjs — обновление HTML-карточек из products в app.js.
После изменения товаров: node scripts/generate-catalog.mjs.

Проверки синтаксиса: node --check app.js && node --check motion.js.
Шрифты Manrope и Cormorant Garamond загружаются из Google Fonts;
предусмотрены локальные запасные шрифты.

Демонстрация: бренд, модели, характеристики и цены вымышлены.
Изображения созданы с помощью ИИ. Заказы продавцу не отправляются,
оплата, сбор контактов и доставка не подключены. Гардероб, избранное
и настройка анимации сохраняются только в браузере посетителя.
